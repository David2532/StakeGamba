# ReleaseProof

ReleaseProof is an independent, evidence-backed preflight for Stake Engine game repositories.

It is designed to reduce avoidable review cycles by checking whether a specific commit contains credible release evidence for:

- reproducible build and publish commands;
- authentication, play, and end-round lifecycle handling;
- interrupted-round recovery;
- dynamic currency and social-mode behavior;
- replay isolation and autoplay confirmation;
- responsive/mobile implementation;
- rules, paytable, browser QA, and CI evidence.

## Launch offers

Every audit identifies the reviewed commit, separates automated proof from heuristic and manual checks, provides exact evidence paths, reproduction commands, and an ordered remediation plan.

ReleaseProof is not an official Stake Engine certification and never guarantees approval. Final approval remains with Stake Engine.
