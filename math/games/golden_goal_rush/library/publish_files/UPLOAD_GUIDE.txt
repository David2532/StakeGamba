Golden Goal Rush Upload Guide

Frontend package:
Use the generated repository-root publish/frontend folder.

Math package:
Use the generated repository-root publish/math folder.

Math folder contents are driven by index.json. Current modes:
- base
- hunt
- rainbow
- bonus_tier1
- bonus

Each mode has:
- <mode>_books.jsonl.zst
- <mode>_lookup.csv

Shared files:
- index.json
- game_config.json
- RTP_AUDIT.json
- RTP_AUDIT.txt
- README_UPLOAD.txt
- UPLOAD_GUIDE.txt

RGS contract:
- The frontend must render round.state from /wallet/play.
- /wallet/end-round remains controlled only by round.active === true.
- Golden Cells, Rainbow reveals, coin/multiplier rewards, Collector awards,
  Cascades and Free Spins are all present in round.state.

RTP calibration:
- Lookup weights are produced by optimization.py against each mode's rtp_target.
- All modes currently achieve 96.50% RTP with no diversity capping.
- See RTP_AUDIT.txt for per-mode hit rate, effective sample size and distribution.

Regenerate:
  cd math/games/golden_goal_rush
  python run.py publish --spins 80000 --bonus-spins 40000 --seed 1

Sync upload folders:
  .\scripts\sync-stake-publish.ps1 -BuildFrontend -SkipMathStalenessCheck
